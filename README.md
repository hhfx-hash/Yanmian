# 研面 · 保研/考研面试练习

当前版本 v0.2：本地交互原型。界面支持电脑与手机屏幕。

## 体验

在项目目录执行：

```powershell
npm.cmd ci
npm.cmd start
```

打开 http://127.0.0.1:5173 。启动时会创建当天开发日志（已有文件不覆盖）。
也可以直接双击 index.html；本地文件与 HTTP 地址的浏览器存储互相独立。

- 点击“体验普通用户”，在头像或工作台修改本科专业，然后开始专业面试。
- 通过“注册”创建新账号，完成训练并退出，再点击“体验管理员”查看用户与训练明细。
- 也可用预置邮箱登录：demo@yanmian.local / Demo123456；admin@demo.local / Admin123456。
- 自行注册的用户使用自己设置的密码；正式版不会保留预置体验密码。

## 范围

专业筛题、手动录题、公开审核、三种来源、单双计时、答案展示、按用户训练记录与后台查看可以体验。
数据只保存在当前浏览器，不跨设备同步；邮箱验证、找回密码、真实服务端权限与互联网部署尚未接入。体验管理员只能看到同一浏览器、同一地址下的账号。
旧版无归属记录保留在管理员“旧版待认领数据”，不计入任何用户统计。

## 验证

```powershell
npm.cmd test
npm.cmd run test:browser
```

浏览器测试使用本机 Microsoft Edge，无窗口运行；结果写入 test-results/。

# 第一版验收标准

## 账户

- 新邮箱可以注册，重复邮箱被明确拦截。
- 未验证邮箱不能开始训练。
- 验证链接过期或重复使用会失败并给出中文提示。
- 忘记密码链接一次性、限时有效。
- 普通用户无法访问管理员接口和页面。

## 题库

- 用户可以新增、编辑和删除自己的私有题目。
- 公开申请进入待审核列表；管理员批准后才出现在公共题库。
- 公共、私有、混合三种来源抽题结果符合选择条件。
- 无题目时有明确提示，不会自动切换来源。

## 训练

- 三种面试模式均可开始。
- 整场和单题计时均可暂停、继续、重置。
- 点击答题完成后才显示参考答案。
- 结束后训练时间、次数、模式和题目明细可查询。
- 刷新或移动端窄屏不会造成主操作不可用。

## 后台

- 管理员可审核题目、管理用户并查看训练数据。
- 禁用用户无法登录或开始训练，恢复后状态正常。
- 关键操作有操作者和时间记录。

## 专业与用户数据新增验收

- 电子信息工程专业只抽到明确适用的知识题，未知专业缺题有明确提示。
- 英语综合可跨专业抽通用题。
- 自建专业题强制适用专业；审核前不进入公共题库。
- 不同普通账号的私有题和训练统计隔离；admin 邮箱前缀不授予权限。
- 管理员看到新注册用户的本科专业、训练次数、有效时长和明细。
- 旧版无归属数据保留但不自动归给当前用户。
- 单题与整场换题、暂停、到期、刷新、结束的时间一致。
- 当前回归覆盖本地体验流程，正式服务器权限验收仍待完成。

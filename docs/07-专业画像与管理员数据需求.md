# 本科专业与管理员用户数据（2026-09-23）

## 已确认的需求

- 注册时填写称呼、邮箱、本科专业；资料页可修改本科专业。
- 研究方向、报考学校、报考专业、本科经历现阶段选填，后续 AI 出题使用这些上下文。
- 专业面试只抽取明确标记适用该本科专业的专业知识题，不用跨专业随机题凑数。
- 英语、综合面试使用通用题，不强制限定本科专业。
- 自建专业题必填适用专业，可指定多个；未收录的专业允许自由填写。
- 无匹配题时显示专业和题库来源，提示录题或主动更换来源；系统不静默切换来源或专业。
- 管理员查看每个用户的邮箱、注册时间、验证状态、本科专业、训练次数、有效时长、最近训练和明细。
- 正式版管理员查看全站数据，普通用户只看自己的资料、私有题和记录。

## 本次已实现的原型行为

- 本浏览器保存用户列表，用稳定用户 ID 关联题目和训练记录。
- 普通注册不会因邮箱包含 admin 而变成管理员；预置管理员有单独体验入口。
- 公共题只包含审核通过项；仅私有来源只包含自己的私有题；混合来源为公开题加自己的题（含待审核题），按 ID 去重。
- 专业按完整名称规范化后精确匹配，不按模糊关键词、相近学科或 AI 猜测专业。
- 示例题覆盖计算机科学与技术、软件工程、电子信息工程、电气工程及其自动化、自动化、机械设计制造及其自动化、教育学，共 11 道专业知识题、4 道通用题。仅用于体验流程，正式公共题库需管理员审校。
- 编辑已公开题并再次申请公开时，重新进入审核；审核期间不进入公共题库。
- 后台人数和统计由实际本地数据计算，不生成虚构用户。
- 密码由 bcryptjs 生成摘要；原型的前端角色判断不是互联网权限边界。

## 旧版数据处理

旧版没有可靠的用户 ID。原有存储键保留不动；旧记录和个人题复制到“旧版待认领数据”，由管理员查看，不猜测归属，不混入任何用户统计。旧版题目需要用户按专业重新录入后才参与新筛题流程。

## 正式版仍待完成

数据库、服务器端身份校验、邮箱验证、找回密码、禁用账号、跨浏览器和跨设备共享、管理员审计。当前本地体验账号不代表已验证邮箱的真实互联网账号。

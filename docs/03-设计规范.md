# 中文界面与视觉设计规范

## 1. 视觉方向

简洁、柔和、清晰。采用低饱和度纯色、圆角卡片和轻阴影，避免密集边框、尖锐装饰和过多渐变。

## 2. 基础令牌

- 页面背景：浅暖灰或浅蓝灰。
- 主色：稳定的蓝色或青蓝色，仅用于主要操作和当前状态。
- 成功色：绿色；警告色：琥珀色；错误色：红色。
- 卡片圆角统一使用 12px 或 16px；按钮圆角统一使用 8px 或胶囊形，不混用过多规格。
- 正文最小字号 14px，移动端可读正文建议 16px。
- 主要按钮高度不低于 40px，移动端触控区域不低于 44px。

## 3. 布局

- 桌面端内容最大宽度建议 1200px，训练页优先突出题目和计时器。
- 移动端采用单列布局，操作按钮允许换行但保持主次顺序。
- 面试训练页固定显示当前模式、计时状态、题目和“答题完成”。
- 参考答案默认折叠或在答题完成后显示，避免提前看到答案。

## 4. 交互

- 所有异步操作显示加载状态，并给出成功或失败反馈。
- 删除、拒绝审核、禁用账号等不可逆或高影响操作必须二次确认。
- 表单错误显示在对应字段附近，使用中文说明修复方式。
- 空状态必须说明原因和下一步动作。
- 键盘操作和移动端触控都要可用。

## 5. 文案

使用“开始训练”“答题完成”“查看参考答案”“申请公开”等明确动词。避免只显示图标而没有文字说明。

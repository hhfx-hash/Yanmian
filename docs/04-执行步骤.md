# 分阶段执行步骤

## 阶段 0：基线与环境（当前阶段）

产出：需求文档、规范文档、日志机制、技术选型记录。

退出条件：目录结构明确，第一版范围冻结，开发环境和部署目标已记录。

## 阶段 1：应用骨架与数据库

顺序：初始化应用 → 配置环境变量 → 接入数据库迁移 → 建立用户、题目、训练记录和审核相关模型 → 建立最小健康检查。

退出条件：迁移可重复执行，敏感配置不入库，模型约束通过测试。

## 阶段 2：账户与权限

顺序：注册登录 → 邮箱验证 → 忘记/重置密码 → 管理员初始化 → 普通用户和管理员权限校验。

退出条件：未验证用户、普通用户、管理员的访问边界均有可验证结果。

## 阶段 3：题库与审核

顺序：题目录入和编辑 → 私有题库 → 公开申请 → 管理员审核 → 公共题库查询和来源筛选。

退出条件：三种来源严格按规则抽取，题目不足时明确报错。

## 阶段 4：面试训练与计时

顺序：模式选择 → 整场/单题计时 → 随机题目 → 答题完成和参考答案 → 训练结束保存记录。

退出条件：刷新、暂停、结束和倒计时到期后的记录一致，桌面和移动端均可操作。

## 阶段 5：后台与统计

顺序：用户管理 → 题目审核工作台 → 训练记录查询 → 基础配置 → 操作日志。

退出条件：管理员可以完成日常管理，普通用户无法访问后台数据。

## 阶段 6：发布准备

顺序：安全配置 → 邮件服务 → 数据备份和迁移演练 → 自动化测试 → 移动端检查 → 部署文档。

退出条件：完成验收清单，明确回滚方式和首个管理员初始化步骤。

每次只推进一个阶段；前一阶段退出条件未满足时，不并行扩展后续功能。

## 当前阶段补充（2026-09-23）

用户反馈触发一次原型修正，内容为专业筛题和本地用户数据闭环。阶段 0 的交互确认已继续推进；阶段 1—6 的正式后端仍待执行。下一轮只推进正式账户与数据库设计及最小流程，不同时扩展 AI、评分或视频。细节见 08-本轮技术决策与后续步骤.md。

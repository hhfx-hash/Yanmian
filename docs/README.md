# 项目开发文档

本目录保存复试面试训练网站的产品需求、技术决策、设计规范、执行步骤和验收标准。

## 文档索引

| 文件 | 用途 |
| --- | --- |
| [01-开发需求.md](./01-开发需求.md) | 第一版范围、角色、功能和明确的暂不实现项 |
| [02-技术与计数规范.md](./02-技术与计数规范.md) | 数据、接口、计时和命名等可执行规范 |
| [03-设计规范.md](./03-设计规范.md) | 中文界面、响应式布局、颜色和交互规范 |
| [04-执行步骤.md](./04-执行步骤.md) | 分阶段开发顺序、每阶段入口和退出条件 |
| [05-验收标准.md](./05-验收标准.md) | 功能、权限、数据和移动端验收清单 |
| [06-风险与决策记录.md](./06-风险与决策记录.md) | 未决问题、风险和已经确认的决策 |
| [开发日志/README.md](../开发日志/README.md) | 每日记录规则和日志索引 |

所有实现前先阅读 `codex.md/README.md` 和本目录的相关标准文件。发生需求变更时，先更新文档，再修改代码。

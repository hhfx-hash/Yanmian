# 第一版开发需求

## 1. 项目目标

面向保研、考研用户提供中文在线复试训练，支持电脑和手机浏览器，后续部署到互联网。

## 2. 用户角色

### 普通用户

- 使用邮箱和密码注册、登录。
- 完成邮箱验证，可通过邮箱找回密码。
- 选择专业面试、英语面试或综合面试。
- 选择整场计时或单题计时，开始、暂停、继续和重置倒计时。
- 从公共题库、自己的私有题库或两者混合抽取题目。
- 答题完成后查看参考答案。
- 录入题目并选择“仅自己可见”或“申请公开”。
- 查看自己的训练时间、训练次数和训练记录。

### 管理员

- 由系统初始化创建，不开放注册。
- 管理用户状态。
- 审核用户申请公开的题目。
- 管理题目、分类、难度和公共题库。
- 查看用户训练时间与训练次数。
- 管理基础配置。

## 3. 第一版功能边界

第一版必须完成：账户注册登录与邮箱验证、密码重置、三类面试模式、双计时模式、三种题库来源、随机抽题、参考答案、用户题库、公开题目审核、训练记录和管理员后台。

第一版暂不接入 AI 出题、AI 评分、录音、语音识别、视频面试、多语言、评论点赞。数据结构应预留题目来源字段，方便后续接入 AI。

## 4. 关键业务规则

1. 未验证邮箱的用户不能开始训练，也不能发布公开题目。
2. “申请公开”的题目必须经过管理员审核；只有审核通过的题目才能进入公共题库。
3. 用户只能查看和编辑自己的私有题目；管理员可管理全部题目。
4. 混合抽题是默认来源；用户也可以只选公共题库或只选自己的私有题库。
5. 选择私有题库时，题目不足必须明确提示用户补充题目，不静默切换到其他来源。
6. 每次训练保存开始时间、结束时间、持续时长、面试类型、计时模式、题目数量和题目明细。
7. 参考答案仅在用户点击“答题完成”后显示。
8. 管理员账号由部署初始化流程创建，密码不得写入代码或提交到版本库。

## 5. 建议页面

登录、注册、邮箱验证、忘记密码、重置密码、用户首页、面试设置、训练页、我的题库、题目编辑、训练记录、管理员首页、题目审核、用户管理、训练数据和系统设置。

## 6. 非功能要求

- 全部界面使用中文。
- 电脑和手机均可使用，主要断点和触控尺寸记录在设计规范中。
- 密码使用成熟密码哈希方案；邮箱验证和重置链接一次性、限时有效。
- 所有需要登录的接口执行服务端权限检查，不能只依赖前端隐藏按钮。
- 关键管理操作记录审计日志。

## 本科专业与管理后台补充

专业面试必须按本科专业匹配专业知识题；英语与综合不强制匹配。后台按用户 ID 关联实际资料和训练数据。规范见 07-专业画像与管理员数据需求.md。本地体验版暂不具备本文件描述的正式服务器权限和邮箱验证能力。

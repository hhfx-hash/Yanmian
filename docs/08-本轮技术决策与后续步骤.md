# 本轮技术决策与后续步骤

## 本轮边界

本轮是已有交互原型的反馈修正：专业筛题、用户归属、管理员数据和相关计时缺陷。既有阶段 1—6 的正式后端验收仍未完成。不得把页面存在等同于对应后端功能完成。

## 已采用方案

| 能力 | 方案 | 理由 |
| --- | --- | --- |
| 页面 | 保留现有 HTML/CSS/JS，分离 domain.js 与 views.js | 控制改动范围，保留用户认可的布局 |
| 原型存储 | localStorage v2，稳定用户 ID，旧版保留 | 支持本浏览器多账号体验并避免错误归属 |
| 密码摘要 | bcryptjs 3.0.2（BSD-3-Clause） | 复用成熟库，不自制密码算法；不是正式鉴权替代品 |
| 本地预览 | serve 14.2.6（MIT） | 复用 npm 静态服务，默认只监听 127.0.0.1 |
| 浏览器验证 | @playwright/test 1.55.1（Apache-2.0），本机 Edge 无窗口运行 | 验证真实操作与 390px 手机布局 |
| 业务规则验证 | Node 自带 test runner | 针对计时、专业与用户数据归属测试 |

依赖安装来源：npm registry；精确版本保存在 package.json 与 package-lock.json。
bcryptjs 的浏览器发行文件及许可证保存在 vendor/，因此双击 index.html 也可以体验，不依赖在线 CDN。
依赖安装后发现 serve 14.2.5 存在上游已修复问题，升级 14.2.6 后 npm audit 为 0 项漏洞。

## 文件职责

- domain.js：专业示例题、来源筛选、计时状态、统计和旧版数据迁移。
- app.js：页面事件、账号体验流程、资料、题库、后台、训练。
- views.js：保留的工作台与设置页模板。
- tests/domain.test.cjs：8 项规则回归。
- tests/browser/flows.spec.cjs：5 项跨页面流程验证。

## 技术实现

### 数据结构
```javascript
// 题目新增 starred 字段
{
  id: '...',
  title: '...',
  answer: '...',
  category: '...',
  majors: [],
  status: 'new',
  starred: false  // 新增
}
```

### 核心函数
- `exportUserData()` - 导出用户数据
- `exportAllData()` - 导出全量数据（仅管理员）
- `importData()` - 导入数据
- `parseBatchFile()` - 解析批量导入文件
- `parseCSV()` - CSV 解析器
- `parseJSON()` - JSON 解析器
- `validateQuestion()` - 题目验证
- `batchImportQuestions()` - 批量导入题目
- `getLast7DaysStats()` - 获取7天统计数据
- `bindQuestionStars()` - 绑定收藏按钮事件
- `toggleQuestionStar()` - 切换收藏状态
- `updateBankList()` - 更新题库列表（支持搜索和筛选）

### CSS 新增样式
- `.data-actions` - 数据操作区域
- `.import-warning` - 导入警告提示
- `.batch-import-guide` - 批量导入指南
- `.batch-errors` - 批量导入错误列表
- `.stats-panel` - 统计面板
- `.trend-chart` - 趋势图表
- `.chart-bar` - 柱状图条
- `.search-input` - 搜索输入框
- `.icon-button` - 图标按钮

### API 集成
```javascript

{
  model: 'deepseek-chat',
  messages: [...],
  temperature: 0.7,
  max_tokens: 4000
}
```

- 明确角色定位（研究生面试官）

- 上下文信息（专业、类型、难度）

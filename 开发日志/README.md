# 开发日志

本目录按日期保存开发记录，文件名格式为 `YYYY-MM-DD.md`。每天至少记录：

- 当日完成事项
- 当日验证结果
- 当前阻塞或风险
- 下一工作日待办事项

## 记录规则

1. 开始工作前运行 `python tools/create_daily_log.py`，不存在当天文件时自动创建。
2. 工作结束前补齐“完成事项”和“待办事项”，不要只写空模板。
3. 每条事项写清对象、动作和结果；涉及验证时记录命令或页面。
4. 需求或标准变化先更新 `docs/`，再在当天日志注明变更原因。
5. 日志不记录密码、令牌、邮箱验证码或其他敏感值。
